= Configuration reference

Runtime properties configure the connection to Topaz. Properties marked with a lock are fixed at build time: the
health check switch, the Dev Service settings, and the security `read-body` and `permissions.enabled` switches.

`api-key`, `tls-configuration-name`, `plain-text` and `deadline` can be set once under `quarkus.topaz.*` and
overridden per service under `quarkus.topaz.authorizer.*` or `quarkus.topaz.directory.*`.
