= Configuration reference

Runtime properties configure the connection to Topaz. A lock marks the properties that Quarkus fixes at build time:

* The health check switch.
* The Dev Service settings.
* The security `read-body` and `permissions.enabled` switches.

Set `api-key`, `tls-configuration-name`, `plain-text` and `deadline` once under `quarkus.topaz.*`. Override them per
service under `quarkus.topaz.authorizer.*` or `quarkus.topaz.directory.*`.
